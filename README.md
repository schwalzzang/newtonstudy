# 뉴턴 아카데미 🍎

> **학창 시절 물리를 포기했던 어른을 위한, 수식 없이 시작하는 물리 교실**

버스가 급정거하면 왜 몸이 쏠릴까? 무거운 것과 가벼운 것 중 뭐가 먼저 떨어질까?
일상에서 겪는 물리 현상을 직접 만지고, 예측하고, 눈으로 확인하며 뉴턴의 운동 법칙을 몸으로 익히는 웹앱입니다.

과학·수학이 어렵게 느껴지는 일반 성인을 대상으로, **수식은 기본적으로 숨기고** 감각과 비유에서 출발합니다.

---

## ✨ 특징

- **예측 먼저(Predict–Observe–Explain)** — 실험 전에 "어떻게 될 것 같나요?"를 먼저 고르고, 실행 결과와 비교합니다. "어, 내 생각과 다르네?"의 인지 갈등이 핵심 학습 장치입니다.
- **3단계 학습 모드** — `체험`(수식 0%) · `개념`(힘 화살표·그래프) · `수식`(선택). 언제든 전환할 수 있습니다.
- **힘 벡터 시각화** — 중력·속도 같은 "보이지 않는 힘"을 색깔 화살표로 실시간 표시합니다.
- **실시간 미니 그래프** — 속도·에너지의 시간 변화를 부담 없이 관찰합니다.
- **슬로모션·일시정지·리셋** — 순간 현상을 천천히 들여다봅니다.
- **O/X 확인 퀴즈 & 오개념 배지** — "많은 사람이 그렇게 생각해요, 실은…" 식의 격려형 해설과, 직접 깨트린 오개념을 모으는 배지.
- **AI 튜터 "뉴턴 선생님"** — 지금 하는 실험(미션·모드·설정값·내 예측·결과)을 이미 알고 있는 Claude 기반 과외 선생님. (선택 기능)
- **자유 실험실** — 커리큘럼과 무관하게 공·상자·경사판을 던지며 노는 샌드박스. 중력을 달만큼 약하게 만들어 볼 수도 있습니다.
- **서버 불필요** — 순수 HTML/CSS/JS. 진행도는 브라우저 `localStorage`에만 저장됩니다.

## 📚 커리큘럼 — 5챕터 15미션

| 장 | 주제 | 일상 소재 |
|---|---|---|
| 1 | 관성의 법칙 | 버스 급정거 · 식탁보 마술 · 멈추지 않는 공 |
| 2 | 힘과 가속도 (F=ma) | 빈 카트 vs 가득 찬 카트 · 미는 힘 · 자유낙하 |
| 3 | 작용과 반작용 | 스케이트장에서 벽 밀기 · 노 젓기 · 로켓 |
| 4 | 마찰과 포물선 | 빗길 제동거리 · 미끄럼틀 · 농구 슛 |
| 5 | 에너지 | 롤러코스터 · 그네 · 당구공 충돌 |

각 미션은 **일상 장면 → 예측 질문 → 시뮬레이션 → 원리 정리 → 확인 퀴즈** 흐름으로 진행됩니다.

## 🚀 실행 방법

빌드 도구가 필요 없습니다. 다만 ES Modules를 쓰므로 `file://`가 아니라 **로컬 서버**로 열어야 합니다.

```bash
# 아무 정적 서버나 사용하면 됩니다
python3 -m http.server 8000
# 또는
npx serve .
```

그런 다음 브라우저에서 `http://localhost:8000` 을 엽니다.

### AI 튜터 사용 (선택)

"뉴턴 선생님"과 대화하려면 Claude API 키가 필요합니다.

1. [console.anthropic.com](https://console.anthropic.com) → **API Keys** 에서 `sk-ant-...` 키 발급
2. 앱 우상단 **🔑 AI 튜터 설정** → 키 붙여넣기 → 저장

> 키는 이 브라우저(`localStorage`)에만 저장되며, Anthropic API 외의 어디에도 전송되지 않습니다.
> 키가 없어도 AI 튜터를 제외한 앱의 모든 기능은 정상 동작합니다.

## 🛠 기술 구성

| 항목 | 선택 |
|---|---|
| 스택 | 순수 HTML/CSS/JS (ES Modules), 빌드 도구 없음 |
| 물리 엔진 | [Matter.js](https://brm.io/matter-js/) (vendor 동봉 + CDN 폴백) |
| 그래프 | 자체 canvas 미니 그래프 |
| AI | Claude Messages API 브라우저 직접 호출 (스트리밍) |
| 저장 | `localStorage` |

### 파일 구조

```
newtonstudy/
├── index.html          # 화면 골격, 오버레이
├── css/style.css
├── js/
│   ├── main.js         # 부트스트랩, 미션 흐름 오케스트레이션
│   ├── state.js        # 진행도·설정·localStorage
│   ├── physics.js      # Matter.js 코어, 슬로모션, 물체 팩토리, 벡터 오버레이
│   ├── missions.js     # 5챕터 15미션 데이터
│   ├── graphs.js       # 실시간 미니 그래프
│   ├── quiz.js         # 예측 질문 + O/X 퀴즈
│   ├── tutor.js        # Claude AI 튜터 (fetch + SSE 스트리밍)
│   └── ui.js           # 공통 UI 유틸
└── vendor/matter.min.js
```

## 🌐 GitHub Pages 배포

이 저장소에는 정적 사이트를 자동 배포하는 GitHub Actions 워크플로(`.github/workflows/deploy-pages.yml`)가 포함되어 있습니다.

1. GitHub 저장소 → **Settings → Pages**
2. **Source** 를 **GitHub Actions** 로 설정
3. 기본 브랜치에 push하면 자동으로 빌드·배포됩니다 (`workflow_dispatch` 수동 실행도 가능).

별도 설정 없이 **Deploy from a branch** 방식으로도 배포할 수 있습니다(사이트가 저장소 루트에 있으므로 브랜치 + `/root` 선택).
