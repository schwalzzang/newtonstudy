# Obsidian 볼트

보험·금융 자료를 옵시디언에서 바로 열 수 있는 마크다운 노트로 인제스트해 둔 공간입니다.
이 폴더(`obsidian/`)를 옵시디언에서 볼트로 열면 됩니다.

## 폴더 구조

| 폴더 | 용도 |
|---|---|
| `00-원문/` | 원본 문서(보도자료·판결문·보고서) 1건 = 노트 1개. 요약 + 메타데이터 + 링크 허브 역할 |
| `10-사례/` | 개별 분쟁조정례·판례. 사실관계 → 쟁점 → 논거 → 시사점 구조 |
| `20-개념/` | 반복 등장하는 용어·법리를 모아둔 원자 노트. 여러 사례에서 링크됨 |
| `90-첨부/` | 원본 PDF 등 첨부파일 |

## 노트 규칙

- **프론트매터**: `title`, `aliases`, `type`(source / case / concept), `tags`, `status`, `ingested`는 항상 채웁니다.
- **태그**: 중첩 태그를 씁니다 — `보험/고지의무`, `사례/분쟁조정례`, `출처/금감원-보도자료`, `쟁점/추가검사`
- **링크**: 개념어가 본문에 처음 등장할 때 위키링크(`[[...]]`)로 연결합니다. 개념 노트는 역으로 사례 노트를 다시 링크해 양방향으로 걸립니다.
- **콜아웃**: 결론은 `> [!success]`, 요약은 `> [!abstract]`로 상단에 둡니다.
- **파일명**: 원문 노트는 `YYYY-MM-DD 제목`, 사례 노트는 `기관 사건번호 - 한 줄 쟁점` 형식.
